# Time Tracker

A simple personal time-tracking web app for recording how I actually spend my day.

## Features

- 24-hour daily timesheet
- Each hour divided into 10-minute blocks
- Custom activities with customizable colors
- Drag and drop activities onto time blocks
- Edit or clear individual time blocks
- View and edit previous days
- Stores the last 30 days of timesheets
- Automatic removal of data older than 30 days
- Daily summary of time spent on each activity

## Tech Stack

- React
- JavaScript
- CSS
- Vite

## Privacy

Timesheet data is stored locally in the user's browser and is not included in this repository.
